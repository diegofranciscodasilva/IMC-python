# Calculadora de IMC

Aplicação de linha de comando em Python que calcula o Índice de Massa Corporal
(IMC) a partir do peso em quilogramas e da altura em metros, e exibe uma
classificação.

## Requisitos

- Python 3.6 ou superior
- Nenhuma dependência externa

## Como executar

No terminal, a partir da pasta do projeto:

```powershell
python calculadora_imc.py
```

Informe o peso em quilogramas e a altura em metros. Use ponto como separador
decimal (por exemplo, `70.5` e `1.75`).

## Classificações

- IMC abaixo de 18,5: abaixo do peso
- IMC de 18,5 a menos de 25: peso normal
- IMC de 25 a menos de 30: sobrepeso
- IMC igual ou superior a 30: obesidade

## Testes

Execute os testes automatizados com:

```powershell
python -m unittest
```

## Observação de saúde

O IMC é apenas uma medida de triagem e não substitui uma avaliação de um
profissional de saúde. As faixas exibidas são referências gerais para adultos
e podem não ser adequadas para crianças, adolescentes, gestantes, atletas ou
outras situações específicas.
